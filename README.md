
## داستان‌های کاربر تکمیلی

| ID | User Story | اولویت |
|---|---|---|
| US-1 | به‌عنوان هنرجو می‌خواهم از مترونوم استفاده کنم تا بتوانم ریتم و زمان‌بندی نواختن ساز را تمرین کنم | Should |
| US-2 | به‌عنوان هنرجو می‌خواهم ابزار کوک ساز داشته باشم تا بتوانم ساز خود را به‌درستی تنظیم کنم | Should |

| US-4 | به‌عنوان مدیر سیستم می‌خواهم دسته‌بندی سازهای موسیقی را مدیریت کنم تا هنرجویان بتوانند آموزش‌ها را راحت‌تر پیدا کنند | Must |

##  معیارهای پذیرش داستان‌های کاربر تکمیلی

### US-1 — استفاده از مترونوم

- امکان روشن و خاموش کردن مترونوم وجود داشته باشد.
- کاربر بتواند سرعت ضرب‌آهنگ را تنظیم کند.
- ضرب‌ها به‌صورت منظم پخش شوند.
- امکان تنظیم سرعت‌های مختلف وجود داشته باشد.

### US-2 — ابزار کوک ساز

- امکان انتخاب نوع ساز وجود داشته باشد.
- ابزار بتواند صدای ساز را دریافت کند.
- میزان کوک بودن سیم یا نت نمایش داده شود.
- نتیجه تنظیم صدا به‌صورت قابل فهم به کاربر نمایش داده شود.

### US-3 — طراحی تمرین و آزمون توسط مدرس

- مدرس بتواند برای هر دوره تمرین یا آزمون ایجاد کند.
- امکان ثبت سؤال و پاسخ وجود داشته باشد.
- هنرجو بتواند به تمرین‌ها پاسخ دهد.
- نتیجه آزمون پس از ثبت پاسخ‌ها نمایش داده شود.

### US-4 — مدیریت دسته‌بندی سازها

- مدیر بتواند دسته‌بندی جدید ایجاد کند.
- امکان ویرایش نام و توضیحات دسته‌بندی وجود داشته باشد.
- امکان حذف دسته‌بندی‌های غیرضروری وجود داشته باشد.
- آموزش‌های مرتبط با هر دسته‌بندی به‌درستی وجود داشته باشد.
